# Business Vision AI

MVP funcional de un radar de oportunidades de negocio y acompanamiento paso a paso. No es un generador de promesas: puntua oportunidades segun presupuesto, tiempo, recursos, habilidades y tolerancia al riesgo; exige validar precios, demanda y requisitos locales.

## Abrir el MVP

La aplicacion se puede abrir directamente con `index.html`. Para instalacion PWA y funcionamiento sin conexion debe servirse por HTTP local o publicarse en un hosting estatico.

Funciones disponibles:

- Onboarding inclusivo con perfil economico y operativo.
- Ranking explicable de seis negocios iniciales.
- Ficha guiada con inversion, proceso, ventas, marca, IA, crecimiento y alertas.
- Receta piloto y advertencias sanitarias cuando corresponde.
- Favoritos, comparador, simulador financiero, tareas de 30/90 dias y exportacion mediante impresion a PDF.
- Mentor guiado de demostracion que no afirma usar datos en vivo.
- Seccion `Opina` con checklist de sesiones y formulario breve de validacion guardado en el dispositivo.
- Tema oscuro, diseno movil y almacenamiento local del progreso.

## Archivos clave

- `index.html`, `styles.css`, `app.js`, `data.js`: producto interactivo.
- `service-worker.js`, `manifest.webmanifest`: base instalable y offline.
- `docs/PRODUCT_BLUEPRINT.md`: estrategia, pantallas, IA, datos, monetizacion y roadmap.
- `docs/FIRST_USER_TEST_CHECKLIST.md`: protocolo de 10 minutos para las primeras entrevistas.
- `supabase/schema.sql`: modelo de datos para la siguiente fase conectada.

## Criterio de producto

Los rangos en USD son escenarios ilustrativos para prueba inicial, no garantias. Antes de recomendar ejecucion real, la fase conectada debe obtener y fechar evidencia local sobre permisos, proveedores, demanda y precios.
